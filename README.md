# Agence Freelance IA

Site vitrine statique prêt pour GitHub et Cloudflare Pages.

## Déploiement Cloudflare Pages

1. Dans Cloudflare : Workers & Pages → Create → Pages → Connect to Git.
2. Sélectionner ce dépôt.
3. Pour un site statique sans build : laisser la commande de build vide et utiliser la racine `/`.
4. Déployer.

## À personnaliser

- Remplacer `contact@votre-domaine.com` dans `script.js` par l'adresse email réelle.
- Ajouter le vrai domaine dans Cloudflare.
- Ajouter les coordonnées et liens sociaux.
